# mlx-cms

Простий веб-контент та CMS-проєкт для роботи з шаблонами, прайсом і виробничими даними.

## Що в проєкті

- Редактор A5-шаблонів
- Прайс товарів
- Облік виробництва
- Простий механізм збереження даних у localStorage або Supabase

## Як запустити

1. Відкрийте проект у браузері через файл [index.html](index.html) або запустіть локальний сервер з кореня проєкту.
2. Для локального сервера можна використовувати, наприклад:

```bash
python3 -m http.server 8000
```

Після цього відкрийте http://localhost:8000.

## Підтримка іконок у тексті

У тексті кнопок, міток або інших HTML-елементів можна використовувати прості токени іконок.

### Доступні токени

- :save:
- :export:
- :import:
- :print:
- :new:
- :delete:
- :close:
- :check:
- :package:

### Приклад

```html
<button x-html="renderTextWithIcons('Зберегти :save:')"></button>
```

Текст буде відображений із відповідною іконкою всередині кнопки.

## Примітка

Якщо потрібно, можна легко розширити список доступних іконок у файлі [js/utils.js](js/utils.js).
